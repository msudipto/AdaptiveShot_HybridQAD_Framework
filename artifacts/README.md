# Artifacts

This directory contains lightweight, curated outputs used to verify and reproduce the manuscript-facing analysis.

- `summary/`: hierarchical aggregation outputs and paired-bootstrap summaries.
- `figures/`: individual diagnostic figures and supporting data.
- `figures_combined/`: four two-panel manuscript figures.

Large checkpoints, per-record finite-shot realizations, and regenerable intermediate artifacts are intentionally excluded from version control and can be recreated with `run_pipeline.ps1`.
