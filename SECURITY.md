# Security Policy

## Supported Versions

This framework is a reproducible research project associated with the NeurIPS 2026 SaTQuML Workshop paper. Security updates are applied directly to the primary development branch.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| < main  | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability, file path leakage, or package constraint exploit within this framework, please do not open a public GitHub issue. Instead, report it privately to the authors via email:

* **Mubassir Serneabat Sudipto** — msudipto@iastate.edu
* **Shakil Ahmed** — ahmeshak@gvsu.edu
* **Ashfaq Khokhar** — akhokhar@ksu.edu
* **Samir M. Iqbal** — iqbalsa@gvsu.edu

Please include a summary of the issue, terminal commands, or steps to reproduce the behavior so we can address it responsibly.
